# Project status — development paused

**Status (November 2026): Not actively maintained. Free to use, learn from, fork and extend under the [MIT licence](LICENSE).**

## Why I've stopped working on it

I started this as a personal hobby project because I enjoy tabletop games, software engineering and exploring how different combat combinations perform. I also wanted to experiment with building a full-stack application using .NET, React, TypeScript and probability calculations.

I learned a lot and enjoyed building it, but the space already has several established tools solving similar problems. Given the competition and the time it would take to keep improving and maintaining a full product, I've decided not to pursue this as an ongoing commercial project. I'm putting that time into other things instead.

Rather than leave the work sitting unused, I wanted to make a **small, self-contained version** available to anyone who might find it helpful.

## You're welcome to use it

If this is useful to you, please feel free to **clone it, run it locally, study the code, fork it or build something of your own**. Contributions and improvements are welcome, but I can't promise that I'll review issues or pull requests or provide support. Please don't depend on an active roadmap or regular updates from me.

This repository contains a **generic example combat-probability calculator**, not the full original game-specific app. The examples are fictional and no third-party game catalogue or artwork is included. The MIT licence covers the original source code here, not other people's game rules, data, logos or artwork. If you add such material, make sure you have the appropriate rights.

Thanks to anyone who takes a look. I hope the code proves useful, even if only as a starting point for your own project.

— Luke
