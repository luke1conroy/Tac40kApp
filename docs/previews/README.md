# Interface previews

These SVG illustrations are **UI previews**, generated from the current React layout and CSS for README presentation. They are **not screenshots of a running build**. The figures in the results image use fictional example profiles and calculations from the repository's simplified model.

To replace these with authentic running-app screenshots later:

1. Start the .NET API on `http://localhost:5080` and the Vite frontend on `http://localhost:5173` (see the root README).
2. Capture the initial scenario builder, click **Analyse Scenario** for the results, and capture the interface at a narrow mobile viewport.
3. Replace the SVG previews with PNG or WebP images in this folder and update the root README links.

Do not upload proprietary game data, third-party images, credentials or private project material.
