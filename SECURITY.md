# Security

Do not report real secrets by opening a public issue. If you discover an accidentally committed credential, revoke/rotate it and contact the repository owner privately through GitHub's private vulnerability reporting (if enabled) or another private contact route you already know.

This repository ships no credentials and has no user accounts. The demo API has no authentication and should not be exposed to the public internet without appropriate rate limits, input-size limits, logging controls, CORS configuration and operational monitoring.

Security fixes are reviewed on a best-effort basis; no service-level commitment is offered.
